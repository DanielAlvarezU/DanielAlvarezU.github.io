# Daniel Alvarez Urbina — Portfolio

This folder is ready for GitHub Pages. It uses plain HTML/CSS/JavaScript and does not require a paid hosting plan.

## Publish it free with GitHub Pages

1. Sign in to GitHub and create a **public repository** named exactly:
   `DanielAlvarezU.github.io`
2. Upload the **contents of this folder** to the repository root (`index.html`, `styles.css`, `script.js`, and the `assets` folder).
3. Commit the files to the `main` branch.
4. Open **Settings → Pages** in the repository.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select **main** and **/(root)**, then save.
7. After GitHub finishes deploying, the site should be available at:
   `https://danielalvarezu.github.io/`

## Before applying to jobs

- Open the site on desktop and mobile.
- Confirm the resume link works.
- Confirm Just Walk-In Clinic, LinkedIn, GitHub, email, and phone links work.
- When you create project-specific GitHub repositories, add their links to the relevant project cards in `index.html`.

## Files

- `index.html` — portfolio content and project cards
- `styles.css` — responsive design
- `script.js` — image lightbox
- `assets/` — project screenshots and resume PDF
