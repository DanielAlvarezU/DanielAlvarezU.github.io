# Update the existing GitHub Pages portfolio

You do **not** need a new repository. Keep using:

`DanielAlvarezU.github.io`

and the public URL remains:

`https://danielalvarezu.github.io/`

Because the URL does not change, the Portfolio link already used in the resume remains valid.

## Replace the current site

1. Download and unzip `DanielAlvarez_Portfolio_v2.zip`.
2. Open the existing `DanielAlvarezU.github.io` repository on GitHub.
3. Delete the old website files/folders from the repository (`index.html`, `styles.css`, `script.js`, old project pages/assets, etc.).
4. Use **Add file -> Upload files**.
5. Drag everything inside this folder into GitHub, including:
   - `index.html`
   - `styles.css`
   - `script.js`
   - all `project-*.html` files
   - the complete `assets` folder
6. Commit the changes to the `main` branch.
7. GitHub Pages will redeploy automatically. No Pages setting needs to change if it is already using `main / (root)`.
8. Open `https://danielalvarezu.github.io/` and hard refresh with `Ctrl + Shift + R` if the old version is cached.
